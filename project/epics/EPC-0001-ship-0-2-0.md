# Ship 0.2.0 as a Rust rewrite with the architecture corrected

This epic realises ADR-0001, the decision to rewrite meowctl in Rust with the
architecture corrected rather than port the Go code (from
project/adrs/ADR-0001-rewrite-rather-than-port.md, high). It migrates the 0.2.0
execution plan, in which every issue is done (from
docs/design/0.2.0-execution-plan.md, high).

## Acceptance criteria

1. `cmd/` and `internal/` are absent and `crates/` holds the fourteen workspace
   crates, which `ls crates` shows (from
   project/adrs/ADR-0001-rewrite-rather-than-port.md, high).
2. The engine holds no renderer: `crates/meowctl-engine/tests/running.rs` holds
   REQ-3051 and `SuspendOutput` appears only in doc comments (from
   project/adrs/ADR-0001-rewrite-rather-than-port.md, high).
3. Exit codes are chosen in one place: `tests/errors.rs` holds REQ-1031 (from
   project/adrs/ADR-0001-rewrite-rather-than-port.md, high).
4. `miette` is absent from every `Cargo.toml`, so the span rendering for defect
   #7 comes from `starlark-rust` (from
   project/adrs/ADR-0001-rewrite-rather-than-port.md, medium).
5. Every requirement ADR-0001 addresses, all 526, lands in exactly one closed
   task (from project/adrs/ADR-0001-rewrite-rather-than-port.md, high).

## Marks

```text
[ ] not started   [>] in progress   [x] done, with evidence
[~] dropped, with the reason        [+] added after approval, with why
```

A task is marked in the commit that advances it, never in a later pass.
