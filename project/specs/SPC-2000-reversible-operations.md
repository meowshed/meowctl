# Reversible operations

## Scope

This component owns the closed set of reversible effects and the write-ahead
journal that makes a failed run undoable. An `Op` is data: it knows how to apply
itself against a `FileSystem` and how to produce the `Op` that undoes it (from
docs/spec/ops.md, high). Adding an effect means adding a variant, and the
compiler asks for its inverse (from docs/spec/ops.md, high).

It lives in the crate `meowctl-ops`, its design is
`docs/design/0.2.0-rust-rewrite.md` §3, and its `v0.1.0` equivalent is
`internal/rollback/` plus the effectful half of `internal/ctx/methods.go` (from
docs/spec/ops.md, high).

## Boundary

The `Op` enum, `apply`, `inverse`, the journal file format, and replay (from
docs/spec/ops.md, high).

| Surface | What it is |
| --- | --- |
| `Op` | Nine journalled variants plus the variants that express an inverse (from docs/spec/ops.md, high) |
| `Op::apply`, `Op::inverse` | Perform the effect through a `FileSystem`; produce the undoing `Op` (from docs/spec/ops.md, high) |
| The journal | Newline-delimited JSON, one record per operation, in the `v0.1.0` format (from docs/spec/ops.md, high) |
| Replay | Applies inverses and reports `ok`, `partial` or `failed` (from docs/spec/ops.md, high) |

## Behaviour

### Operations

`Op` has exactly nine journalled variants: `WriteFile`, `AppendFile`,
`CopyFile`, `Symlink`, `LinkFile`, `Mkdir`, `Download`, `DefaultsWrite` and
`PlistSet` [REQ-2001] (from docs/spec/ops.md, high). It also carries variants
that express an inverse, `Remove`, `RemoveDir`, `RestoreBackup` and `Nothing`
[REQ-2100], and none of those is written to a journal [REQ-2101] (from
docs/spec/ops.md, high).

`Op::apply` performs the effect through a `FileSystem` [REQ-2002] and by no
other route [REQ-2102] (from docs/spec/ops.md, high). `Op::inverse` is computed
before the effect is applied, from the state the effect is about to destroy
[REQ-2003] (from docs/spec/ops.md, high). Applying an `Op` and then its inverse
restores the filesystem to its prior state [REQ-2004], for every variant
[REQ-2103], and a property test over `MemFs` checks it [REQ-2104] (from
docs/spec/ops.md, high). An `Op` that finds the system already in its target
state still produces a correct inverse [REQ-2005] (from docs/spec/ops.md, high).

### Inverses

| Variant | Inverse |
| --- | --- |
| `WriteFile` | Restores the prior content when the file existed [REQ-2010], and deletes the file when it didn't [REQ-2105] (from docs/spec/ops.md, high) |
| `AppendFile` | Wraps what it appends in begin and end markers carrying an identifier [REQ-2011]; the inverse removes the block those markers delimit, without truncating the file [REQ-2106]. The identifier is generated by default [REQ-2107] and the caller can override it [REQ-2108] (from docs/spec/ops.md, high) |
| `CopyFile` | Deletes the destination [REQ-2012] (from docs/spec/ops.md, high) |
| `Mkdir` | Removes the directory only when meowctl created it [REQ-2013], and does nothing when it already existed [REQ-2109] (from docs/spec/ops.md, high) |
| `Symlink` | Re-creates the prior symlink when one existed [REQ-2014], and removes the link when none did [REQ-2110] (from docs/spec/ops.md, high) |
| `LinkFile` | Removes the symlink [REQ-2015], and restores the backed-up original when a backup was taken [REQ-2111] (from docs/spec/ops.md, high) |
| `Download` | Restores the prior content when the destination existed [REQ-2016], and deletes the file when it didn't [REQ-2112] (from docs/spec/ops.md, high) |
| `DefaultsWrite`, `PlistSet` | Each records the prior value [REQ-2017], read while computing the inverse and before the write [REQ-2115]; the inverse restores it [REQ-2113], and deletes the key when no prior value existed [REQ-2114] (from docs/spec/ops.md, high) |

### The journal

The journal is a file of newline-delimited JSON records, one per operation, in
the format `internal/rollback/rollback.go` writes: a sequence number, the phase,
the component, the kind and the inverse payload [REQ-2020] (from
docs/spec/ops.md, high). A journal written by `v0.1.0` replays under `v0.2.0`
[REQ-2116], and the reverse [REQ-2190] (from docs/spec/ops.md, high).

A record is appended and flushed to disk before its operation is applied
[REQ-2021] (from docs/spec/ops.md, high). Replay applies inverses in reverse
sequence order [REQ-2022] (from docs/spec/ops.md, high), and reports one of
three outcomes, every inverse applied, some applied or none, which map to the
`ok`, `partial` and `failed` values of `state.toml` [REQ-2024] (from
docs/spec/ops.md, high).

After a successful run, the journal is truncated [REQ-2025] (from
docs/spec/ops.md, high). A dry run journals no `Op` [REQ-2026] and creates no
journal file [REQ-2119] (from docs/spec/ops.md, high).

## Failure paths

| Condition | What happens |
| --- | --- |
| An individual inverse fails during replay | Replay continues [REQ-2023] and reports which inverses failed [REQ-2117], with the outcome `partial` or `failed` [REQ-2024] (from docs/spec/ops.md, high) |
| A journal record can't be parsed | Replay of the records around it goes on [REQ-2030]; the record is reported and skipped [REQ-2120] (from docs/spec/ops.md, high) |
| An inverse's target no longer exists | The inverse succeeds [REQ-2031] (from docs/spec/ops.md, high) |
| Appending the journal record fails | The operation fails, and its effect isn't applied [REQ-2032] [REQ-2021] (from crates/meowctl-ctx/src/state.rs:142-164, high) |
| The record before an append was torn | The new record stays readable on its own, and replay loses only the torn one [REQ-2141] |
| The journal can't be opened or created | The run stops before any hook runs, naming the path [REQ-2140] |
| A non-empty journal exists at startup | It is reported as an interrupted previous run [REQ-2118] (from docs/spec/ops.md, high) |
| The process crashes between the append and the effect | The journal replays a no-op, which is safe [REQ-2021] (from docs/spec/ops.md, high) |
